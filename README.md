
# Run and deploy your Perosnal Home management App

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/33ece61b-70d9-432b-aff5-f84b124f6df3

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
